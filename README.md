# VINARIA · 红酒图书馆

一个沉浸式红酒学习与私人品鉴记录网站。以“酒宫藏书阁”为视觉概念，把产区、年份、葡萄品种、单宁、酸度、酒体、香气、适饮期与餐酒搭配整理成可探索的馆藏卡片。

## 核心体验

- 12 款示例名酒与年份学习档案
- 按产区、葡萄品种与风味关键词检索
- Gallery 画廊 / Wine Shelf 酒架双视图
- 酒款详情抽屉：年份札记、结构刻度、香气与配餐
- 标记“喝过”、收藏“想喝”、五星评分与品鉴笔记
- 数据自动保存在浏览器 `localStorage`
- 桌面、平板与手机响应式设计

## 本地运行

```bash
pnpm install
pnpm dev
```

生产构建：

```bash
pnpm build
pnpm preview
```

## 技术栈

React 19、Vite、Lucide Icons、纯 CSS 响应式视觉系统。图片资源均已压缩为 WebP。
